## 2. 为什么会走到下一个阶段

### 从快速检索到 Agent

第一阶段提高了常见问题的表现。Top5、Top10、Top40 的结果很接近，只能说明在当时的数据和方案下，继续增加候选深度没有明显收益，不能证明所有检索方法都到达上限。

决定引入 Agent 的另一半证据来自失败轨迹：问题要求“全部地区”，候选里却反复出现已找到的地区；某个路径为空后，系统缺少继续探索的动作。这里需要维护目标集合、观察工具返回并决定下一步。

### 从外部 Agent 到训练

强模型配合 Skill 先验证了任务可行性，也留下了成功与纠错轨迹。随后我需要把这些轨迹变成专用模型能够学习的行为，而不只是收集最终答案。

SFT 学习固定示范；OPD 让学生先行动，再取得教师对学生 token 的评价；任务 RL 根据最终结果比较同题的不同尝试。三者解决的问题不同，并不要求每个模型都按相同顺序训练。

## 3. 用一条合成问题贯穿整条链

> 以下地区、指标和值全部为解释机制而合成；这不是历史评测样本，也不参与仓库中的效果统计。

**问题：某城市甲、乙、丙三个地区在指定季度的工业用电量分别是多少，哪个地区最高？**

为便于说明，假设三个地区数据同单位、同统计范围，月度值可加，且无缺月或重复月份。

### 第一步：业务约束比语义相似更具体

一次平铺召回可能找到“全市工业用电量”。它命中了主题和城市，却没有覆盖三个地区。Judge 要检查的是地区集合、时间、单位和可计算关系。

### 第二步：Agent 维护覆盖状态

| 时刻 | 观察或动作 | 已覆盖 | 下一步 |
| --- | --- | --- | --- |
| 起点 | SEARCH_PATH 找到地区主题入口 | 空 | 展开目录 |
| 展开后 | 甲、乙有直接入口，丙在当前路径为空 | 空 | 记录三个待处理目标 |
| 首批取数 | 甲、乙的季度值返回 | 甲、乙 | 保留丙为缺项，检查关联路径 |
| 回退后 | 找到丙的三个月单月值 | 甲、乙 | 校验时间与口径后取回并求和 |
| 完成前 | 三个地区均有可解释结果 | 甲、乙、丙 | 检查覆盖、计算与最终答案 |

假设甲、乙季度值分别为 30、27，丙的三个月单月值为 9、10、12，则丙的季度值是 31，且为三者最高。甲、乙的取数互不依赖时可以同轮调用；丙的路径恢复需要先读取上一轮反馈。

无法找到某地区时，Agent 应说明已找到的结果和缺失项，并遵守探索预算。正确表达缺失与“完整回答了三个地区”是不同完成状态。

### 第三步：轨迹怎样成为训练数据

Teacher Session 保存搜索、取数、空结果、回退和最终回答。转换时保留原来的同轮调用组与错误上下文；不能因为最后答案正确，就随意删掉前面的失败动作。

进入 SFT 时，问题、工具说明和工具返回是条件；模型生成的调用与回答才是监督目标。是否训练非空 thinking 取决于模板与 mask，不能仅凭消息中出现了 `<think>` 就判断。

同源问题产生的不同 Teacher、Runtime 和 slash/nonslash 版本，应在数据隔离时视为同一组。历史数据建设与更严格的切分要求见 [第三章](03-data-and-trajectory.md)。

### 第四步：OPD 与 RL 怎样使用这道题

- **OPD**：学生自己走轨迹，教师评价这些真实生成 token 的概率；教师不替学生重新跑一条正确路径。
- **任务 RL**：同题采样多条 Session，比较实际任务 reward。若 reward 只匹配季度指标 ID，丙的月度求和路径可能被低估；需要明确 reward 的任务范围与等价规则。

这里暴露出两个监督目标的差别：模仿教师偏好的动作，和满足业务完成标准，不一定给出完全相同的反馈。

### 第五步：部署后仍要执行任务

即使模型会输出正确调用，如果 parser 不认识它的格式，工具也不会执行。验收要检查完整过程，而不是只检查服务能否返回文本。

## 4. 我会优先回看的四个问题

| 看到的现象 | 我先检查什么 | 不足以直接得出的结论 |
| --- | --- | --- |
| 扩大 TopK 没涨分 | 候选是否重复、正确目标是否出现、长尾是否缺覆盖 | 所有检索方案都无效 |
| SFT loss 下降但任务不提升 | 模板、调用合法性、训练数据与真实状态分布 | 模型一定需要更大规模 |
| RL reward 上升但离线分下降 | reward 能否解析当前输出、目标是否一致、数据和评测版本 | 某个训练机制一定导致退化 |
| 同一权重跨 Runtime 差距大 | Skill 加载、消息重渲染、调用映射、失败恢复 | 权重本身已经变差 |

这是我的复盘顺序，不是每种问题都已经完成因果消融的声明。具体成绩与可解释范围见 [实验与数据口径索引](06-experiment-index.md)。
